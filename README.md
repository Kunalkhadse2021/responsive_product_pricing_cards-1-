# Responsive Product Pricing Cards

## Description
Responsive Product Pricing Cards built using HTML, CSS, and JavaScript. Features attractive pricing plans, modern designs, hover effects, and a mobile-friendly layout.

## Features
- Multiple pricing cards
- Attractive user interface
- Modern CSS styling
- Hover effects
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` – Webpage structure
- `style.css` – Styling and responsive layout
- `script.js` – Interactive functionality

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
